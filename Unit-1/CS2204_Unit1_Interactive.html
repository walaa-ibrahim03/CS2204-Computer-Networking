2. غيّري تصميم الشبكة

الرسم تخطيطي؛ أثر العطل الحقيقي يعتمد على تفاصيل الأجهزة والروابط والبروتوكولات.

3. ماذا تفعل كل طبقة؟

اختاري طبقة لترَي دورها أثناء فتح صفحة ويب.

مقارنة النماذج

OSI — 7 Layers

Application → Presentation → Session → Transport → Network → Data Link → Physical

Internet stack — 5 Layers (Kurose & Ross)

Application → Transport → Network → Link → Physical

4. جرّبي بنفسك على Mac Terminal

افتحي Terminal واكتبي الأوامر التالية واحدًا واحدًا. اضغطي على الأمر لنسخه.

الخطوة 1 — هل يصل الرد؟
ping -c 4 example.com

راقبي time= وهو زمن الذهاب والعودة بالمللي ثانية، إذا كانت الوجهة ترد على ICMP.

الخطوة 2 — كم قفزة على الطريق؟
traceroute example.com

كل سطر قد يمثل موجّهًا على الطريق. بعض الأجهزة لا ترد، فتظهر نجوم.

الخطوة 3 — شاهدي HTTP
curl -I https://example.com

ستظهر رؤوس استجابة HTTP، مثل رمز الحالة وخصائص الخادم.

لا يمكن لهذه الصفحة المحلية تشغيل Terminal أو قراءة شبكة جهازك؛ التجربة الحقيقية تتم عبر الأوامر أعلاه.
